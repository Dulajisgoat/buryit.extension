# Icons required

This folder must contain four PNG files before Chrome will load the extension:

- `icon16.png`
- `icon32.png`
- `icon48.png`
- `icon128.png`

These are binary image files and cannot be generated as text, so add them manually (any square PNG at the matching pixel size works for local testing). Chrome will refuse to load BuryIt as an unpacked extension if any of these files are missing.
